# Consolidado_Niveis_Ensino
Junção de bases contendo informações (fictícias)

#Objetivo

Agrupar de forma automatizada bases com níveis de ensino diferentes. 

#Problema 

Me foi solicitado uma automação capaz de consolidar bases distintas, retirar dados sensíveis e identificar cada ocorrencia à sua respectiva origem(nível de ensino).

#Solução 

Para o projeto, criei este código que utiliza dados fictícios, mas de estrutura semelhante à original.
Ele se baseia em uma técnica ETL (Extract, Transform, Load), com consolidação vertical de múltiplas fontes de dados.

#Tecnologia

Excel
Visual Basic (VBA)

#Resultado

-Agregar bases separadas em um consolidado principal.
-Redução do trabalho manual.
-Padronização do processo de atualização.
-Maior praticidade na manutenção dos relatórios.

#Observações

Teste a macro em uma cópia do arquivo original antes de utilizá-la em relatórios de produção.
